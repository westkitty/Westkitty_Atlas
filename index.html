Reading the constellation

Every dot is a verified public GitHub repository. A solid line records a specific source-backed statement or package match. A dashed line is a proposed integration, not existing code flow.

  • Orbit: drag one finger or a mouse. Pinch, wheel or use + / − for zoom.
  • Inspect: click a dot or a line, or use the search box. Every connection has an explanation and source links.
  • Keyboard: / search, arrow keys rotate the focused map, F flat projection, Home reset camera, ? this guide, Esc dismiss menus.
  • Modes: All shows every connection; Documented shows only source-backed links; Possibilities shows proposed ones only.
  • Data: Export a versioned JSON snapshot. Import validates all records and remains session-only. Restore reopens the built-in source snapshot.
  • Performance: Low effects, flat projection and hidden unreviewed dots are available for constrained devices.

The packaged evidence snapshot dates from 2026-11-08. Hosted visits can check the public Repo_Dex feed without opening source URLs. The local HTML remains offline-capable. No private repositories are included.
